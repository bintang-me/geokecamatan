Disclaimer/Penafian:

Website Cari Kecamatan merupakan alat bantu pencarian data administrasi nama kecamatan di Negara Republik Indonesia berdasarkan titik koordinat yang bersifat informatif.

Sumber Data:

  • Primer: Geoportal Kebijakan Satu Peta, Badan Informasi Geospasial (BIG) — poligon batas wilayah administrasi dan identifikasi lokasi.
  • Sekunder: ArcGIS Esri, OpenStreetMap (Nominatim), BigDataCloud.
  • Deteksi Perairan: Is On Water API (NASA ASTER Water Body Database).

Batasan dan Risiko:

  • Akurasi hasil sangat bergantung pada ketersediaan dan ketepatan data dari masing-masing API pihak ketiga pada saat permintaan dilakukan dan terkadang terjadi kesalahan.
  • Tidak semua API merespons setiap saat. Gangguan layanan atau Cross-Origin Resource Sharing (CORS) dapat menyebabkan hasil salah atau kosong.
  • Koordinat di luar batas wilayah Negara Republik Indonesia tidak dapat diproses untuk pencarian kecamatan.
  • Jangan gunakan untuk penetapan batas wilayah, sengketa perbatasan, sengketa pertanahan, maupun segala keperluan hukum dan putusan lainnya yang bersifat mengikat.
